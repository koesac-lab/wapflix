# Handset themes

WAPFLIX supports five Nokia-inspired handset themes. Each changes the chassis silhouette, key geometry and navigation cluster - not just colours.

| Theme | Chassis | Keys | Nav |
|---|---|---|---|
| 3310 | Classic blue, rounded | Soft rounded keys | Standard 3-column |
| 8210 | Slim dark grey | Small flat angular keys | Compact |
| 6310 | Brown/tan | Larger keys | 4-way pad styling |
| 7110 | Green | Elongated keys | Large curved oval nav + pill OK |
| 3210 | Plum | Chunky keys | Standard |

## Switching

Options -> HANDSET -> OK cycles through the five models. The choice persists in localStorage.

## Button mapping

All themes share the same logical keypad:

- 2/8 navigate
- 4/6 seek during playback
- 5 select
- 1 Info
- 3 Share
- 0 Connection quality
- * Home
- # Backlight

The 7110 theme reshapes the nav cluster and OK key to evoke its distinctive curved scroll button.
